## 🚀 核心开源项目

### FinTerminal

**围绕 MCP、量化分析、RAG、Agentic Research、金融可视化与可审计数据溯源构建的 Local-first AI 金融研究基础设施。**

FinTerminal 是我当前的主要公开开源项目。

**工程能力**

- MCP 研究工具层
- 量化与统计分析
- 带来源归因的本地 RAG
- 市场数据与预测
- 金融可视化与报告生成
- SHA-256 数据溯源
- Electron + React + TypeScript 桌面端
- Python + FastAPI 后端
- Apache-2.0 开源许可

**开源维护链路**

`change → pull request → CI → Ruff → pytest → desktop build → merge → release gate → packaged artifacts → SHA-256 checksums → GitHub Release`

**仓库：** [lucaschang2021/finterminal](https://github.com/lucaschang2021/finterminal)

## 🧠 正在构建

### Mobius

正在开发中的 **以 Codex 为核心的工程工作流与编排系统**。

Mobius 探索如何将 AI coding agents 组织进严谨的软件工程流程，覆盖规划、实现、整合、测试、审查、Git 操作、技术文档与长期项目知识。

### FlowTracer

正在开发的信息监控与研究雷达系统，围绕自定义信息源、结构化检索、桌面推送、记忆与知识工作流构建。

### Rasputin

实验性 AI 基础设施项目，探索多 Agent 编排、成本感知模型路由、可靠性与可审计自动化。

> 标记为“正在开发”的项目均处于持续演进阶段，不被描述为成熟稳定的公开发行版本。
