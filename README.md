## 🚀 Featured Project

### FinTerminal

**Local-first AI financial research infrastructure built around MCP, quantitative analysis, RAG, agentic research, visualization, and auditable data provenance.**

FinTerminal is my primary public open-source project and currently includes:

- MCP-based research primitives for AI clients
- quantitative and statistical analysis workflows
- local RAG and source-attributed research
- market-data and forecasting infrastructure
- financial visualization and report generation
- SHA-256-linked data provenance and integrity verification
- Electron + React + TypeScript desktop application
- Python + FastAPI local backend
- Apache-2.0 open-source licensing

The project is maintained through a structured OSS workflow:

`change → pull request → CI → Ruff → pytest → desktop build → merge → release gate → packaged artifacts → checksums → GitHub Release`

**Repository:** [lucaschang2021/finterminal](https://github.com/lucaschang2021/finterminal)
